# Data Guard Pro — حارس البيانات (مراقب الإنترنت الذكي)

تطبيق أندرويد احترافي فائق الدقة لمراقبة استهلاك بيانات الإنترنت عبر شبكات الجوال (Mobile Data) وشبكات الواي فاي (Wi-Fi)، مبني بأحدث تقنيات أندرويد الرسمية (Kotlin & Jetpack Compose) بتصميم Material 3 حديث، مع دعم كامل للغة العربية واتجاه الكتابة من اليمين إلى اليسار (RTL).

---

## 🌟 الميزات الرئيسية

### 1. إحصائيات دقيقة وحقيقية من نظام Android
- الاعتماد المباشر على واجهات برمجة تطبيقات النظام الرسمية: `NetworkStatsManager` و `ConnectivityManager` و `TrafficStats`.
- التمييز الصارم بين:
  - **السرعة اللحظية:** قياس معدل النقل الفعلي في الثانية (KB/s و MB/s) للرفع والتنزيل.
  - **استهلاك الفترة المحددة:** حساب دقيق لحجم التنزيل (Rx) والرفع (Tx) خلال نافذة زمنية محددة.
  - **السجلات التراكمية التاريخية:** تخزين لقطات يومية دورية في قاعدة بيانات محليّة.
- **عدم اختلاق أي بيانات (No Mock Data):** إذا لم تتوفر إحصائيات من النظام لفترة معينة، يعرض التطبيق رسالة توضيحية شفافة تبين القيود بدلاً من عرض أرقام وهمية.

### 2. محرك اختيار التواريخ والفترات الزمنية المتقدم
يوفر التطبيق مرونة استثنائية لمراجعة الاستهلاك في أي وقت:
- **اليوم (Today):** الاستهلاك منذ بداية اليوم وحتى اللحظة الحالية.
- **أمس (Yesterday):** الاستهلاك الدقيق ليوم أمس كاملاً من 00:00 إلى 23:59:59.
- **الأسبوع الحالي والأسبوع السابق (This Week & Last Week):** مقارنة الأسبوع الحالي بالماضي.
- **الشهر الحالي والشهر السابق (This Month & Last Month):** تتبع الاستهلاك الشهري الكامل.
- **اختيار أي يوم سابق عبر التقويم (Specific Past Day):** إمكانية اختيار أي تاريخ محدد في الماضي وعرض استهلاك ذلك اليوم على حدة.
- **فترة زمنية مخصصة (Custom Range):** تحديد تاريخ بداية ونهاية مخصصين.

### 3. مراقبة استهلاك التطبيقات (Per-App Telemetry)
- رصد استهلاك كل تطبيق مثبت على الجهاز (اسم التطبيق، أيقونة التطبيق، اسم الحزمة، حجم استهلاك الجوال، استهلاك الواي فاي، والإجمالي).
- شريط بحث فوري للبحث باسم التطبيق أو اسم الحزمة.
- تصفية حركة البيانات: (الكل / بيانات الجوال فقط / واي فاي فقط).
- 5 خيارات ترتيب متقدمة:
  1. الأكثر استهلاكاً (Highest Usage)
  2. الأقل استهلاكاً (Lowest Usage)
  3. الأعلى استهلاكاً للبيانات الخلوية (Mobile Usage)
  4. الأعلى استهلاكاً للواي فاي (Wi-Fi Usage)
  5. الترتيب الأبجدي (Alphabetical)
- **شاشة تفاصيل التطبيق المستقلة (App Detail Screen):** توفر تفصيلاً دقيقاً لبيانات التنزيل والرفع، النسبة المئوية من إجمالي استهلاك الجهاز، ونوع التطبيق (نظام / مستخدم)، مع أزرار سريعة لفتح التطبيق أو إدارة إعداداته في النظام.

### 4. إدارة الباقات والحصص والتنبيهات الذكية (Data Allowance)
- تخصيص سعة الباقة (جيجابايت) وتحديد يوم بداية الدورة الشهرية (من 1 إلى 31) مع معالجة أطوال الأشهر تلقائياً.
- ضبط حد استهلاك يومي للإنترنت للتنبيه عند الإفراط.
- مؤشر دائري جذاب يوضح حجم المستهلك، المتبقي، ونسبة الاستهلاك.
- نظام إشعارات ذكي عند الوصول إلى عتبات محددة: **50%، 75%، 90%، 100%**.
- **منع تكرار الإشعارات (Deduplication):** يتم تسجيل كل إشعار مرسل في قاعدة البيانات المحلية لمنع إزعاج المستخدم بتكرار نفس التنبيه لنفس الدورة.

### 5. الرسوم البيانية والتقارير المتقدمة
- رسم بياني شريطي يومي تفاعلي يوضح اتجاه الاستهلاك اليومي.
- مقارنة بصرية سريعة بين استهلاك شبكة الجوال وشبكة الواي فاي.
- تصدير بيانات الاستهلاك التاريخية كملف CSV لمشاركتها أو تحليلها في برامج الجداول الحسابية.

### 6. المهام الخلفية الموثوقة (WorkManager)
- جدولة دورية تلقائية عبر `WorkManager` تعمل كل فترة لتحديث الإحصائيات، والتحقق من حدود الباقة، وإطلاق التنبيهات حتى في حال إغلاق التطبيق.

## 🏗️ الهيكلية البرمجية والتقنيات (Architecture & Tech Stack)

تم بناء التطبيق باتباع أفضل ممارسات هندسة برمجيات أندرويد الحديثة:

| المكون | التقنية المستخدمة |
| :--- | :--- |
| **لغة البرمجة** | Kotlin 2.x |
| **واجهة المستخدم** | Jetpack Compose مع Material Design 3 |
| **نمط البناء** | MVVM (Model-View-ViewModel) مع Clean Architecture |
| **قاعدة البيانات المحلية** | Room Database (KSP) لتخزين اللقطات وسجلات الإشعارات |
| **التفضيلات والإعدادات** | Jetpack DataStore Preferences |
| **المعالجة غير المتزامنة** | Kotlin Coroutines & Reactive StateFlow |
| **المهام المجدولة في الخلفية** | AndroidX WorkManager |
| **إحصائيات الشبكة** | `NetworkStatsManager`, `ConnectivityManager`, `TrafficStats` |
| **الاختبارات الآلية** | JUnit 4, Robolectric, Kotlinx Coroutines Test |

### هيكل الحزم داخل المشروع:
```text
com.example/
├── data/
│   ├── local/              # كيانات Room وقواعد البيانات (UsageDao, Entities)
│   ├── model/              # نماذج البيانات (AppNetworkUsage, TimeframeUsage, ...)
│   ├── network/            # مراقبة الاتصال وواجهات NetworkStatsManager
│   ├── preferences/        # إدارة إعدادات وتفضيلات المستخدم عبر DataStore
│   └── repository/         # مستودع البيانات الموحد (UsageRepository)
├── domain/
│   ├── analytics/          # محرك التحليلات والكشف عن القفزات غير المعتادة
│   ├── billing/            # حاسبة فترات الباقة وحدود التواريخ الشهرية والأسبوعية
│   └── limits/             # تقييم تجاوز الحصص والتنبيهات
├── notification/           # إدارة قنوات وإرسال إشعارات التنبيه
├── ui/
│   ├── components/         # المكونات المشتركة، عدادات السرعة، حوار اختيار التاريخ
│   ├── navigation/         # شريط التنقل السفلي وإدارة المسارات
│   ├── screens/            # شاشات التطبيق (الرئيسية، التطبيقات، الباقات، الرسوم، الإعدادات...)
│   ├── theme/              # نظام الألوان والطباعة Material 3
│   └── viewmodel/          # نمط العرض وإدارة الحالة (MainViewModel)
├── util/                   # دوال التنسيق المساعدة (تحويل البايتات، التواريخ)
└── worker/                 # عامل WorkManager للعمليات الدورية في الخلفية
```

## 🔒 الخصوصية والأمان

- **100% محلي على الجهاز (Local-Only):** يعمل التطبيق بالكامل داخل بيئة جهاز المستخدم، ولا يقوم بنقل أو جمع أو إرسال أي بايت من بياناتك إلى أي خادم خارجي أو طرف ثالث.
- **الحد الأدنى من الصلاحيات المطلوبة:**
  1. `PACKAGE_USAGE_STATS` (صلاحية الوصول إلى بيانات الاستخدام): صلاحية نظام أندرويد الخاصة لقراءة استهلاك الشبكة لكل تطبيق وللجهاز عموماً.
  2. `POST_NOTIFICATIONS`: لإرسال إشعارات تحذيرية عند اقتراب نفاد باقة البيانات.
  3. `ACCESS_NETWORK_STATE`: لمعرفة نوع الاتصال النشط (واي فاي أم شبكة خلوية).

## ⚙️ القيود التقنية لنظام Android وكيفية التعامل معها

1. **إعادة تشغيل الجهاز (Device Reboot):**
   - تقوم واجهة `TrafficStats` في نظام أندرويد بتصفير عداداتها مع كل إعادة تشغيل للجهاز.
   - **الحل في التطبيق:** يعتمد التطبيق على `NetworkStatsManager` الذي يحتفظ بسجلات استهلاك حزم الشبكة عبر فترات زمنية محددة في ملفات النظام، كما يقوم التطبيق بحفظ لقطات دورية في قاعدة بيانات Room المحلية لضمان استمرارية السجلات بعد إعادة التشغيل.

2. **فترة احتفاظ النظام بالبيانات التفصيلية:**
   - قد لا يحتفظ نظام التشغيل بسجلات دقيقة للتطبيقات القديمة جداً إذا تم تنظيف ذاكرة التخزين المؤقت للنظام. عند محاولة قراءة تاريخ قديم جداً لا تتوفر فيه سجلات بالنظام، يوضح التطبيق للمستخدم بشفافية أن النظام لا يحتوي على بيانات مسجلة لذلك التاريخ بدلاً من افتعال بيانات غير حقيقية.

3. **الوصول لإحصائيات استهلاك التطبيقات:**
   - تتطلب قراءة استهلاك التطبيقات موافقة صريحة من المستخدم عبر شاشة "الوصول إلى بيانات الاستخدام" (Usage Access). يوفر التطبيق إرشادات واضحة وزراً ينقل المستخدم مباشرة إلى الإعدادات لتفعيلها.

## 🚀 البناء والتشغيل (Build & Run Instructions)

### المتطلبات الأساسية:
- **Java Development Kit (JDK):** الإصدار 17 أو أحدث.
- **Android SDK:** Compile SDK 36، و Min SDK 24.
- **Gradle:** استخدام أداة Gradle المدمجة عبر سطر الأوامر.

### أوامر سطر الأوامر:
- **تشغيل اختبارات الوحدة واختبارات Robolectric:**
  ```bash
  gradle :app:testDebugUnitTest
  ```
- **بناء حزمة التثبيت (Debug APK):**
  ```bash
  gradle assembleDebug
  ```
  *سيتواجد ملف APK المبني في المسار التالي:*
  `app/build/outputs/apk/debug/app-debug.apk`
